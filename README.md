Autonomous Navigating Vehicle (May 2025)

Coded in collaboration with a project partner.
This is the Arduino IDE code for a small cart to autonomously navigate a course consisting of a white path
on a black mat. This is for an academic project.

An Arduino Nano-board is used for the software coding. The cart primarily consists of two motors and three 
sensors (left and right sensors for detecting the white path, one "bumper" sensor for start and end).

The code is of course made for the specific path provided, and the speeds are heavily optimised to be 
maximally consistent on the mat and wheel materials while remaining above a min path completion time.
